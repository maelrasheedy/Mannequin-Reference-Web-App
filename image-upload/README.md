# Image Upload Feature

## Overview

This is my image upload feature for our Mannequin Reference Web App senior project.

The purpose of this feature is to allow users to upload a sketch from their computer and preview it on the webpage.

## Features

- Users can select an image from their computer.
- Supports JPG, JPEG, and PNG images.
- Maximum file size is 10 MB.
- Displays a preview of the selected image.
- Hides the upload instructions when an image is selected successfully.
- Allows users to remove the uploaded image.
- Restores the original upload instructions after removing an image.
- Displays messages for successful uploads, invalid file types and      files that are too large.

## Files

- **index.html** — Creates the image upload interface.
- **style.css** — Controls the appearance of the upload section and image preview.
- **script.js** — Handles image selection, validation, preview, and removal.

## How to Use

1. Open the Mannequin Reference Web App.
2. Go to the Workspace tab.
3. Click **Choose File** in the image upload section.
4. Select a JPG, JPEG, or PNG image that is 10 MB or smaller.
5. The selected image will appear in the preview area.
6. Click **Remove Image** to clear the preview and select another image.

## Future Development

The image upload feature will eventually be connected to the Search button so users can search for reference images using their uploaded sketch.

Currently, the feature handles image selection and preview only. It does not send the image to a search system.
